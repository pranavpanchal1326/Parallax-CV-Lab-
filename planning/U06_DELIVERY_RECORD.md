# U06 delivery — local grounded guide support

3 October 2026 · AI-L1 local demonstrator complete · Ollama selected by the user.

The assistant at `#/assistant` answers questions using four designer-reviewed project guides: sampling, lighting evidence, evidence/equipment workflow and camera geometry. Its interface keeps the question beside the cited answer and readable manual. Local AI selects relevant sections; answer text and learning prompts are copied from the reviewed guide. Hint-first is the default, with a separate explanation preference. Contextual preparation links select E01/E06 without exporting experiment evidence.

This delivers real local inference, not an authored answer demonstration. The installed `llama3.2:3b` model (digest `a80c4f17acd55265feec403c7aef86be0c25983ab279d83f3bcd3abbcb5b8b72`) ran through Ollama 0.35.0. No download or cloud service was used. The first observed cold call took 101.1 seconds. The subsequent final evaluation's 27 completed local calls took 143–423 ms each, median 221 ms including local adapter overhead, with 6,625 input and 290 output tokens. These timings describe this warmed machine and bounded passage-selection task, not general AI performance. Electricity, device energy and monetary costs were not measured; no metered-saving claim follows.

The Node service builds trusted context from its own registry, rejects client roles/evidence/arbitrary fields, and checks published revision plus content fingerprint before and after inference. Draft, withdrawn, changed and unknown sources cannot produce a verified answer. The structured output contains only selected section IDs. Unretrieved, invented, duplicate, excessive or incomplete selections fail closed. Numeric reference/sample/alias facts are checked against the existing scientific calculation; the model does not compute or invent measurements. Questions involving unsynchronized browser work or live equipment conditions lack context and receive a bounded explanation. There are no operational tools, authoritative bookings, staff release decisions or student-grade access.

Cancel retains the question and aborts the local request; late results cannot replace the current interface. Provider failure leaves the guide readable. API failure labels the bundled reader publication-unchecked and disables generation. Source/selection changes label any earlier answer. Citations navigate to the exact guide/section with a revision parameter; an unavailable requested revision is labelled rather than silently presented as that revision. The current source registry can be withdrawn without a rebuild; rebuilding updates the offline copy.

Review flags are explicit and anonymous-session scoped. The UI states which question/passages will enter the local memory queue, its pending status and expiry/restart limitation. There is no staff notification or automatic correction. Server-held cache/flag ownership is tested across separate cookies; the public display has no assistant entry or review projection. This is local isolation, not institutional authentication.
