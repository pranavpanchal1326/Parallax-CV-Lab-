Composition decisions are intentional: editorial hierarchy and asymmetric workspaces replace repeated panels; assessment gives paired evidence the main area; asset history reads as a ledger; mobile has one primary lookup/report action. Original art is reused, and original project pages remain the visual reference. Student journeys gain a fixed previous/next dock with bottom spacing and focus scroll margins; actionable form controls retain their own task-specific labels.

The map bridge is generated into `public/lab-map/` by `scripts/build-map.cjs`. It reuses original CSS, geometry, model and the 3D module through the edition server. It receives only equipment status labels and example time. Its source escapes incoming text; it does not accept private staff/assessment records or access either primary storage key.
